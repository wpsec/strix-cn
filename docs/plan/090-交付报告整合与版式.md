# 090 交付报告整合与版式

> 文档状态：历史方案已废弃。当前报告回归上游原生目录和章节结构，仅保留中文本地化；单漏洞报告按需追加非表格的 `攻击链路` 路径视图。

## 目标

本方案原计划将分散的漏洞 Markdown 整合为一份独立交付报告，现不再作为实现目标。当前保留上游的执行摘要、单漏洞 Markdown、CSV、JSON 和 SARIF 产物，供复核与系统导入。

## 当前交付结构

1. `penetration_test_report.md`：上游原生执行摘要
2. `vulnerabilities/*.md`：上游原生单漏洞明细的中文化版本
3. `vulnerabilities.json`、`vulnerabilities.csv`、`findings.sarif`：机器可读产物
4. 单漏洞报告中的 `攻击链路`：按请求/动作顺序展示的纵向路径，不使用表格

## 历史实施结果

- 该历史方案曾生成封面、目录和 HTML 交付页；这些内容已删除，避免报告偏离上游原生结构。
- 当前 `writer.py` 只负责上游原生 Markdown、CSV、JSON 和 SARIF 产物，并将标题与字段翻译为中文。

## 当前验收条件

- 完成运行后存在上游原生结构的 Markdown、JSON、CSV 和 SARIF 产物。
- 单漏洞报告的中文章节顺序与上游一致。
- `attack_chain` 存在时以路径视图呈现，不生成攻击链表格。
- 报告生成、渲染和相关回归测试通过。
