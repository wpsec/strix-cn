# 维护计划索引

本文档用于集中管理 `strix-cn` 的维护、同步、汉化与交付计划。后续所有计划文档统一放在 `docs/plan` 目录下，采用 `NNN-主题.md` 的编号形式维护。

## 目标

- 建立并维持简体中文默认体验，覆盖用户可见面与开发文档
- 固化上游同步、冲突裁决、交付报告和验证流程
- 保持命令、配置键、模型 ID、协议字段和其他技术字面量不变
- 通过测试和残留审计，避免后续回退或行为漂移

## 推进原则

- 计划文档只放在 `docs/plan`
- 所有新增用户可见文案默认使用简体中文
- 允许保留的英文仅限白名单内容，例如环境变量、命令、模型名、CVE/CWE、HTTP 头、代码块、JSON 键、上游产品名
- 同一术语在 README、docs、CLI、TUI、报告中保持统一译法
- 上游同步类文档必须写清基线版本、冲突分层、验证清单与下次 SOP

## 维护规则

- 新增计划文档时，先在本文件登记，再创建具体文档
- 每份计划文档至少包含：目标、范围、输入、变更点、验收条件、剩余问题
- 汉化相关实施完成后，应同步更新对应阶段的状态与剩余问题
- 主线同步完成后，应补充本轮热点文件、裁决原则和最小验证集，便于下一次复用
- `strix-cn` 独有能力如果要宣称“必须保留”，必须同时登记能力契约、热点文件和 focused guard test
