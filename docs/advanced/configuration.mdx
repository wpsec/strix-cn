你可以通过环境变量或配置文件来配置 Strix。

## LLM 配置

<ParamField path="STRIX_LLM" type="string" required>
  以 LiteLLM 格式指定模型名，例如 `openai/gpt-5.4`、`anthropic/claude-sonnet-4-6`，或兼容网关下的 `openai/<your-model>`。
</ParamField>

<ParamField path="LLM_API_KEY" type="string">
  LLM 提供商的 API Key。本地模型或云厂商原生认证方式（如 Vertex AI、AWS Bedrock）可不填写。
</ParamField>

<ParamField path="LLM_API_BASE" type="string">
  自定义 API base URL。也接受 `OPENAI_API_BASE`、`LITELLM_BASE_URL` 或 `OLLAMA_API_BASE`。
</ParamField>

<ParamField path="LLM_EXTRA_HEADERS" type="string">
  额外附加到每次 LLM 请求上的 HTTP 头，格式为 JSON 对象，例如 `{"X-Feature-Key":"value","X-Tenant":"acme"}`。适用于要求额外路由头、租户头或计费头的 OpenAI-compatible 网关。
</ParamField>

<ParamField path="LLM_DISABLE_STREAMING" type="string">
  关闭模型流式输出。设置为 `1`、`true`、`yes` 或 `on` 时生效。适用于某些兼容网关、受限网络或不稳定流式实现。
</ParamField>

<ParamField path="LLM_TIMEOUT" default="300" type="integer">
  LLM 请求超时时间，单位为秒。
</ParamField>

<ParamField path="STRIX_LLM_MAX_RETRIES" default="5" type="integer">
  LLM API 短暂失败时的最大重试次数。
</ParamField>

<ParamField path="STRIX_REASONING_EFFORT" default="high" type="string">
  控制推理模型的思考强度。可选值为 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。`quick` 扫描模式下默认会降为 `medium`。
</ParamField>

<ParamField path="STRIX_MEMORY_COMPRESSOR_TIMEOUT" default="30" type="integer">
  上下文压缩操作的超时时间，单位为秒。
</ParamField>

## 模型画像（可选）

LiteLLM 的能力表不一定收录国内网关的新模型（如 token-plan 的 `qwen3.8-flash`），此时上下文窗口、
输出上限与成本只能走兜底值。Strix 支持用本地画像文件声明"你这个网关"的真实参数——数据归用户，
程序不内置任何供应商数值。

创建 `~/.strix/model-profiles.json`（或用 `STRIX_MODEL_PROFILES` 指定路径），键为模型名（忽略
provider 前缀，大小写不敏感）：

```json
{
  "qwen3.8-flash": {
    "max_input_tokens": 32768,
    "max_tokens": 8192,
    "input_cost_per_mtok": 0.8,
    "output_cost_per_mtok": 4.8
  }
}
```

| 字段 | 含义 | 来源 |
|------|------|------|
| `max_input_tokens`（或 `context_window`） | 上下文窗口 | 供应商模型列表 / 计费页 |
| `max_tokens`（或 `max_output_tokens`） | 单次响应输出上限；Anthropic 协议必填 `max_tokens` 时用它 | 同上 |
| `input_cost_per_mtok` / `output_cost_per_mtok` | 每百万 token 单价（美元），用于报告费用统计 | 计费页 |

行为规则：画像字段覆盖对应兜底，但**不改变**请求构造行为（tokenizer 选择、reasoning 支持等仍由
路由决定）；未识别的字段会被忽略并告警；文件不存在或损坏时一切维持默认。生效点：上下文压缩时机、
Anthropic 协议输出额度、报告成本估算。

## 独立去重模型

漏洞去重是一个成本较低、结构化很强的分类任务。默认复用主模型；如需把真正的渗透测试能力和去重判断拆开，可单独指定一个更便宜或更快的模型。

<ParamField path="STRIX_DEDUPE_MODEL" type="string">
  用于判断候选漏洞是否与现有报告重复的模型。未设置时回退到 `STRIX_LLM`。
</ParamField>

<ParamField path="DEDUPE_LLM_API_KEY" type="string">
  独立去重模型的 provider API Key。
</ParamField>

<ParamField path="DEDUPE_LLM_API_BASE" type="string">
  独立去重模型的 API Base 地址。当去重模型与主模型不在同一个兼容网关或 provider 时使用。
</ParamField>

<ParamField path="DEDUPE_LLM_EXTRA_HEADERS" type="string">
  独立去重模型的额外 HTTP 头，格式同 `LLM_EXTRA_HEADERS`。它不会自动继承主模型的额外请求头。
</ParamField>

<ParamField path="STRIX_DEDUPE_REASONING_EFFORT" type="string">
  独立去重模型的推理强度。未设置时使用该模型自身的默认行为。
</ParamField>

## 可选功能

<ParamField path="PERPLEXITY_API_KEY" type="string">
  Perplexity AI 的 API Key。配置后可启用实时 Web 搜索，用于 OSINT 与漏洞研究。
</ParamField>

<ParamField path="POSTMAN_API_KEY" type="string">
  Postman API Key（`PMAK-…`）。用于通过 `postman://<collection-uid>` 拉取 collection，或通过 `postman://<collection-uid>?env=<environment-uid>` 拉取 environment 并解析变量。若直接传本地 collection 导出文件，则不需要。
</ParamField>

<ParamField path="STRIX_TELEMETRY" default="1" type="string">
  遥测开关。设置为 `0`、`false`、`no` 或 `off` 可关闭 PostHog、Scarf 与 OTEL 遥测。
</ParamField>

<ParamField path="TRACELOOP_BASE_URL" type="string">
  远程 OpenTelemetry 导出地址。未设置时，Strix 只在本地保留 tracing 数据。
</ParamField>

<ParamField path="TRACELOOP_API_KEY" type="string">
  远程 tracing 导出使用的 API Key。只有同时设置 `TRACELOOP_BASE_URL` 与 `TRACELOOP_API_KEY` 时，远程导出才会启用。
</ParamField>

<ParamField path="TRACELOOP_HEADERS" type="string">
  可选的 OTEL 额外请求头，支持 JSON 对象或 `key=value,key2=value2` 形式。适用于 Langfuse 或自建 OTLP 网关。
</ParamField>

未配置远程 OTEL 变量时，Strix 仍会把完整运行遥测写入本地：

```bash
strix_runs/<run_name>/events.jsonl
```

## Docker 配置

<ParamField path="STRIX_IMAGE" default="ghcr.io/usestrix/strix-sandbox:1.3.0" type="string">
  指定用于沙箱容器的 Docker 镜像。
</ParamField>

<ParamField path="DOCKER_HOST" type="string">
  Docker daemon socket 路径，适用于远程 Docker 或自定义运行环境。
</ParamField>

<ParamField path="STRIX_RUNTIME_BACKEND" default="docker" type="string">
  沙箱运行时后端。默认使用 Docker。
</ParamField>

## 沙箱配置

<ParamField path="STRIX_SANDBOX_EXECUTION_TIMEOUT" default="120" type="integer">
  沙箱操作的最大执行时间，单位为秒。
</ParamField>

<ParamField path="STRIX_SANDBOX_CONNECT_TIMEOUT" default="10" type="integer">
  连接沙箱容器的超时时间，单位为秒。
</ParamField>

## 配置文件

Strix 默认把配置保存到 `~/.strix/cli-config.json`。你也可以通过 `--config` 指定自定义配置文件：

```bash
strix --target ./app --config /path/to/config.json
```

配置文件格式：

```json
{
  "env": {
    "STRIX_LLM": "openrouter/z-ai/glm-5.3",
    "LLM_API_KEY": "sk-...",
    "LLM_API_BASE": "https://your-gateway.example/v1",
    "LLM_EXTRA_HEADERS": "{\"X-Tenant\":\"acme\"}",
    "LLM_DISABLE_STREAMING": "false",
    "STRIX_REASONING_EFFORT": "high"
  }
}
```

## 示例配置

```bash
# 必填
export STRIX_LLM="openai/your-compatible-model"
export LLM_API_KEY="your-api-key"

# 可选：兼容网关或本地模型
export LLM_API_BASE="https://your-gateway.example/v1"
export LLM_EXTRA_HEADERS='{"X-Tenant":"acme"}'
export LLM_DISABLE_STREAMING="false"

# 可选：启用 Web 搜索
export PERPLEXITY_API_KEY="pplx-..."

# 可选：调高推理强度
export STRIX_REASONING_EFFORT="max"

# 可选：受限网络环境
export HTTP_PROXY="http://127.0.0.1:7897"
export HTTPS_PROXY="http://127.0.0.1:7897"
export ALL_PROXY="socks5://127.0.0.1:7897"

# 可选：自定义超时
export LLM_TIMEOUT="600"
export STRIX_SANDBOX_EXECUTION_TIMEOUT="300"
```
