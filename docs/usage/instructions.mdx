title: "自定义说明"
description: "通过自定义指令引导 Strix 的测试行为"
---

你可以通过说明（instructions）为扫描补充上下文、聚焦方向、排除项和交付要求。`strix-cn` 默认推荐直接使用中文编写说明；当前分支也默认输出中文报告。如果你需要英文或双语结果，可以在说明里显式写明。

## 行内说明

```bash
strix --target https://app.com --instruction "重点测试认证绕过、越权和找回密码流程"
```

## 文件说明

如果说明较复杂，建议放到文件中：

```bash
strix --target https://app.com --instruction-file ./pentest-instructions.md
```

## 常见使用方式

### 认证测试

说明里只写测试目标和关注点，不要直接写账户密码：

```bash
strix --target https://app.com \
  --instruction "重点测试登录后会话固定、越权和找回密码流程"
```

### 聚焦范围

```bash
strix --target https://api.example.com \
  --instruction "重点测试 /api/users 相关接口中的 IDOR、批量赋值和水平越权"
```

### 排除项

```bash
strix --target https://app.com \
  --instruction "不要测试 /admin 和 /internal 路径，也不要触发短信与支付相关流程"
```

### API 测试

```bash
strix --target https://api.example.com \
  --instruction "请求头需要带上 X-API-Key，占位值由运行环境提供。重点测试限流绕过、签名校验和重放攻击。"
```

## 目标登录凭据

如果本次测试需要使用已授权的登录账户，请使用专门参数，而不是把凭据写进说明：

```bash
strix --target https://app.com \
  --auth-username '<username>' \
  --auth-password-stdin \
  --instruction "登录后重点测试订单、用户资料和管理后台的越权问题"
```

`--auth-password-stdin` 会在当前终端安全读取密码，或从标准输入读取一行密码。Strix 只会把它注入本次沙箱的内存环境变量，不会写入 Prompt、日志、运行记录或总报告。

## 说明文件示例

```markdown instructions.md
# 渗透测试说明

## 重点关注
1. 用户资料接口中的 IDOR
2. 不同角色之间的提权
3. JWT Token 篡改

## 不在范围内
- /health 接口
- 第三方集成
```

<Tip>
说明越具体，Strix 越能优先探索最有价值的攻击路径。对于中文团队，直接用中文描述范围、约束和输出要求通常最省心；敏感凭据请走专门参数或安全注入通道，不要写进说明文件。
</Tip>

## Workspace 文件

说明内容会进入 Prompt。想让 Strix 拿到一个可供使用的文件（如字典、API 规范或笔记），用 `--workspace-file`；扫描开始前 Strix 会把该文件放入沙箱 workspace。

```bash
strix --target https://app.com --workspace-file ./wordlist.txt
```

文件会落在 `/workspace/<文件名>`。想指定目标位置，写 `PATH:DEST`；`DEST` 必须是 `/workspace` 内的路径。

```bash
strix --target https://app.com \
  --workspace-file ./openapi.yaml:specs/openapi.yaml \
  --workspace-file ./notes.md
```

想放几个文件就重复几次该选项。Strix 会在 agent 任务里列出这些文件，agent 因此知道去哪里读取。

适用于所有 workspace 文件的规则：

- 文件在沙箱内只读。
- 目标位置必须留在 `/workspace` 内。
- 目标位置不得落在被扫描目录内部，因为那些文件来自被测目标本身；这样的文件会被跳过并记录警告。
- 两个文件不能占用同一个目标位置。

<Note>
workspace 文件是给 agent 使用的数据。它不是扫描目标，其内容也不会改变扫描指令。
</Note>

<Warning>
Do not place secrets in a workspace file. The sandbox runs untrusted target
code, so treat anything you place there as readable by the target.
</Warning>
