## 基本用法

```bash
strix (--target <target> | --target-list <path> | --mount <path> | --burp-port <port>) [options]
```

## 选项

<ParamField path="--target, -t" type="string">
  指定测试目标。支持 URL、仓库、本地目录、域名、IP、API spec 文件（OpenAPI / Swagger `.json` / `.yaml`、Postman collection 导出），以及通过 id 直接拉取的 Postman collection（`postman://<collection-uuid>`）。可重复传入多个 `--target`。

  当目标是本地目录时，Strix 会把目录以实时挂载方式暴露给沙箱，代理读写的是你的真实文件（`.git` 除外）。建议先提交或暂存本地改动。

  当目标是 API spec 时，Strix 会先读取契约并把其声明的 base URL 作为授权范围的一部分。推荐与实际部署地址一起传入，例如：

  ```bash
  strix --target ./openapi.yaml --target https://api.example.com
  ```

  <Note>
    新建扫描时，至少需要提供 `--target`、`--target-list`、`--mount` 或 `--burp-port` 之一。
  </Note>

  <Note>
    通过 `postman://<collection-uuid>` 拉取 Postman collection 需要配置 `POSTMAN_API_KEY`。如果 collection 依赖 Postman environment 变量，可追加 `?env=<environment-uuid>`。
  </Note>
</ParamField>

<ParamField path="--target-list" type="string">
  指向目标列表文件的路径。文件中每个非空、非注释行表示一个目标；以 `#` 开头的行会被忽略。可重复传入，并可与 `--target` 组合使用。
</ParamField>

<ParamField path="--mount" type="string">
  兼容参数：把本地目录作为代码工作区挂载进沙箱，但不把它视为显式扫描目标。适用于你希望保留旧命令习惯，或只给代理一个工作目录、由 `--instruction` 决定要做什么的场景。可重复传入。

  <Note>
    当前本地目录目标本身就走挂载模式，`--mount` 主要用于兼容旧工作流与“仅挂工作区、不授目标范围”的场景。
  </Note>
</ParamField>

<ParamField path="--burp-port" type="integer">
  将 Strix 的 Burp 上游代理入口固定绑定到指定本机端口。可单独使用，进入 Burp 被动代理模式；也可与 `--target` 搭配，显式限定目标主机。
</ParamField>

<ParamField path="--instruction" type="string">
  为本次扫描提供自定义说明，例如排除项、重点漏洞类型、测试边界或报告要求。当前分支默认中文体验，推荐直接使用中文。
</ParamField>

<ParamField path="--instruction-file" type="string">
  从文件读取较长的测试说明。适合保存详细范围、排除项和交付要求。
</ParamField>

<ParamField path="--auth-username" type="string">
  提供已授权的目标登录账户。必须与 `--auth-password-stdin` 一起使用。账户名不会写入报告、Prompt 或运行记录。
</ParamField>

<ParamField path="--auth-password-stdin" type="boolean">
  从当前终端的隐藏输入，或从标准输入读取一行目标账户密码。密码只会在本次运行中注入沙箱环境变量，不会进入命令行历史、Prompt、运行记录或总报告。
</ParamField>

<ParamField path="--allow-credential-attacks" type="boolean">
  显式授权本次测试执行弱口令、密码喷洒、登录重试等凭据攻击验证。默认只允许使用提供的账户做正常登录，不允许扩展成口令攻击。
</ParamField>

<ParamField path="--non-interactive, -n" type="boolean">
  以无头模式运行，不启动 TUI。适用于 CI/CD、服务器任务和批量调用。
</ParamField>

<ParamField path="--scan-mode, -m" type="string" default="deep">
  扫描深度，可选 `quick`、`standard`、`deep`。`quick` 适合 CI 快扫，`deep` 适合深入审计。
</ParamField>

<ParamField path="--scope-mode" type="string" default="auto">
  代码范围模式：`auto`（CI / 无头模式下自动启用 PR diff-scope）、`diff`（强制只看变更文件）、`full`（关闭 diff-scope）。
</ParamField>

<ParamField path="--diff-base" type="string">
  指定 diff-scope 对比的目标分支或提交，例如 `origin/main`。
</ParamField>

<ParamField path="--config" type="string">
  指向自定义配置文件（JSON）的路径，用于替代 `~/.strix/cli-config.json`。
</ParamField>

<ParamField path="--max-budget, --max-budget-usd" type="number">
  整次扫描的 LLM 总预算上限（美元）。系统会在模型响应完成后检查预算，并在接近阈值时向代理发送渐进式收尾提醒。
</ParamField>

<ParamField path="--max-turns" type="integer" default="500">
  每个代理允许的最大 turns 数。达到上限后，该代理会被强制停止。
</ParamField>

<ParamField path="--resume" type="string">
  按历史运行名恢复之前的扫描，即 `strix_runs/<run_name>` 目录。恢复时会自动带回原始目标、工作区挂载、Burp 端口和历史状态，不能与 `--target`、`--target-list` 或 `--mount` 混用。
</ParamField>

## 示例

<Note>
  如果你使用国内可访问的兼容网关、自建模型入口或本地模型，优先通过 `STRIX_LLM` + `LLM_API_BASE` 配置模型；如果访问模型或安装源需要代理，可在运行前设置 `HTTP_PROXY`、`HTTPS_PROXY` 和 `ALL_PROXY`。
</Note>

```bash
# 基础扫描
strix --target https://example.com

# 本地代码扫描
strix --target ./app-directory

# Burp 被动扫描：浏览器 -> Burp -> Strix -> 目标站点
strix --burp-port 8081

# Burp 被动扫描 + 显式限制目标主机
strix --target https://example.com --burp-port 8081

# API spec + live target（OpenAPI / Swagger / Postman collection）
strix --target ./openapi.yaml --target https://api.example.com
strix --target ./collection.postman_collection.json --target https://api.example.com

# Postman collection 通过 id 实时拉取
export POSTMAN_API_KEY="PMAK-..."
strix --target "postman://<collection-uuid>?env=<environment-uuid>"

# 从文件读取目标
strix --target-list ./targets.txt

# 兼容参数：只挂载工作目录
strix --mount ./huge-monorepo --instruction "Review the changed auth flow"

# 自定义指令
strix --target api.example.com --instruction "重点测试 IDOR、认证绕过和业务逻辑缺陷"

# 使用已授权登录账户（运行时安全读取密码）
strix --target https://app.example.com --auth-username '<username>' --auth-password-stdin

# 针对指定基线强制启用 diff-scope
strix -n --target ./ --scan-mode quick --scope-mode diff --diff-base origin/main

# 恢复之前中断的运行
strix --resume pentest_abc123

# 使用兼容网关
export STRIX_LLM="openai/your-compatible-model"
export LLM_API_BASE="https://your-gateway.example/v1"
export LLM_EXTRA_HEADERS='{"X-Tenant":"acme"}'
strix --target ./app-directory
```

## 退出码

| 代码 | 含义 |
|------|------|
| 0 | 扫描正常结束。交互模式始终返回 `0`；无头模式下表示未发现漏洞 |
| 1 | 启动前或运行过程中发生致命错误，例如环境变量缺失、Docker 不可用、配置非法或未处理异常 |
| 2 | 发现漏洞（仅无头模式） |
